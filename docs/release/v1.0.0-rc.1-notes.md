# Broadside 1.0.0-rc.1 release notes (summary)

The first 1.0 release candidate. It carries the API intended for 1.0: from here to 1.0.0 only fixes land, and changes a fix forces. 1.0.0 follows the soak period set out in the [general-availability criteria](ga-criteria.md).

All 17 packages ship as `1.0.0-rc.1` under one version, the viewer packages included. This page is the hand-written summary for review. The full generated notes (every change since `0.1.0-preview.10`, grouped by type, with the public API diff of each package) are the `1.0.0-rc.1` section of [`CHANGELOG.md`](../../CHANGELOG.md), and the GitHub release carries the same text.

## Highlights

### Reading (`Broadside`)

- Opens files from disk, memory or a URL (an `HttpClient` source reads only the byte ranges it needs), including encrypted, password-protected, damaged and incomplete files. Reading is lenient: every repair is recorded as a diagnostic, and strict mode throws instead.
- Every diagnostic has a stable, documented code: the [diagnostic-code catalog](https://michaelstonis.github.io/Broadside/articles/diagnostics/) lists them, with the stability policy that applies from 1.0.
- Text extraction in reading order with words, lines and positions; the structure tree on tagged files and layout detection on untagged ones.
- Forms, annotations, outlines, attachments, optional content and metadata as typed views over the file; signature validation.
- New since preview.10: painted images can be extracted from a page, and a `PdfImage` saved as PNG or JPEG (#607).
- Every resource limit untrusted input can reach is documented in the [threat model](../threat-model.md), and the parsers and codecs were fuzzed and reviewed for v1 (#273, #274).

### Writing and editing (`Broadside`, `Broadside.Layout`, the font packages)

- A canvas API for text, paths, images, shadings and transparency, with fonts embedded and subset automatically.
- Page insertion, removal and reordering, merge and split, form filling and flattening, annotations, encryption on save, and incremental or full saves.
- Signing (CMS and PAdES, with timestamps and long-term validation data).
- PDF/A-2, -3 and -4 and PDF/UA-1, PDF/UA-2 and Well-Tagged PDF output, and auto-tagging of untagged files.
- The document builder in `Broadside.Layout` lays out headings, paragraphs, tables, images, headers and footers, and produces tagged PDF. It still carries `[Experimental("BROADSIDE0001")]`; see the open question at the end of the [API review](../api-review-v1.md).
- `Broadside.Fonts.Standard14` and `Broadside.Fonts.Cmaps` supply the standard fonts and the predefined CJK character maps for files that do not embed them.

### Rendering (`Broadside.Rendering` and the backends)

- A managed software rasterizer that gives the same bytes on Linux, Windows and macOS, x64 and Arm64, and native backends for SkiaSharp, CoreGraphics, Direct2D, Android Canvas and WebGL 2.
- Faster on average than PDFium and pdf.js on the pinned real-world pages: see the [performance comparison](https://michaelstonis.github.io/Broadside/articles/performance/) (#275). Since preview.10, tint transforms, tiling patterns, patch meshes, CMYK groups and blending got faster (#602, #603, #611, #612, #613).
- Trimming, Native AOT and WebAssembly are verified on every target (#272).

### Viewers (`Broadside.Viewer` and its six controls)

- One engine renders pages as tiles off the UI thread, with controls for Blazor WebAssembly, .NET MAUI, Avalonia, Uno Platform, WinUI 3 and WPF.
- Smooth scrolling and zooming, text selection and copy, search with background indexing, outline and thumbnails, links, form filling, smart dark mode and screen-reader support in every control.
- The viewers are part of 1.0: they are covered by the API freeze, the API guards, package validation and every release gate, and ship as 1.0.0 with the library. Since preview.10, a window's scaling event is released with the control, search yields within the frame budget, and the WPF control copies a padded tile correctly (#599, #600, #274).

## Breaking changes since 0.1.0-preview.10

The v1 API freeze (#262) fixed every naming and shape rule the API review found broken, so code written against preview.10 needs these changes. Each break is recorded against the preview.10 baseline in the affected package's `CompatibilitySuppressions.xml`; the [API review](../api-review-v1.md) has the package-by-package detail, and the changelog has the full public API diff.

**Renamed types and members**

| Package | Before (preview.10) | Now (1.0) |
|---|---|---|
| `Broadside.Rendering.WebGL` | `WebGLRenderer` | `WebGLBackend` |
| `Broadside.Rendering.CoreGraphics` | `CoreGraphicsRenderer` | `CoreGraphicsBackend` |
| `Broadside.Rendering.Direct2D` | `Direct2DRenderer` | `Direct2DBackend` |
| `Broadside.Rendering.Direct2D` | `Direct2DDriver`, property `Driver`, constructor parameter `driver` | `Direct2DDeviceType`, `DeviceType`, `deviceType` |
| `Broadside` | `PdfOptions.WithLoggerFactory` | `PdfOptions.UseLoggerFactory` |
| `Broadside` | `GenerateAppearances()` on text, choice and toggle-button fields | `WriteAppearances()` |
| `Broadside.Viewer` | `TextSelection`, `AnnotationLayer`, `AccessibilityBridge` `.LoadPageAsync` | `.ReadPageAsync` |
| `Broadside.Viewer` | `AccessibilityBridge.LoadPage` | `AccessibilityBridge.ReadPage` |
| `Broadside.Viewer` | `DocumentOutline.LoadAsync`, `PageLabelTable.LoadAsync` | `.ReadAsync` |
| `Broadside.Viewer` | `IAccessibleElementProvider` | `IAccessibleElementSource` |

**Changed signatures**

- `DisplayList.Replay` and `DisplayList.BeginReplay`, and `SoftwareRasterizer.BeginRender(list, ...)`, take `(..., IProgress<double>? progress, CancellationToken cancellationToken)`: the cancellation token is now last.
- A trailing `CancellationToken cancellationToken = default` was added to `WebGLBackend.InitializeAsync`, `CopySelectionAsync`, the MAUI panels' `RefreshAsync`, the Blazor viewer's `InitializeAsync` and `StartAsync`, and `DocumentSession.OpenAsync(Stream)` and `DocumentSession.OpenAsync(HttpClient, Uri)`.
- Optional parameters were split into explicit overloads: `PdfDocument.AddEmbeddedFile`, `EmbedFont`, `EmbedTrueTypeFont`, `GetColorConverter(source, conversion)`, `PdfPage.CreateHitTestIndex(list)`, the `PdfEngine(IOptions<PdfOptions>)` constructor, `TableElement.Border(Length)` and `ToBitmap(image, fillColor)`. Source that called them compiles unchanged; binaries built against preview.10 must be rebuilt.

## Install check

Run after `v1.0.0-rc.1` is published, on Linux, Windows and macOS, each in an empty folder with the .NET 10 SDK:

```sh
dotnet new console -n BroadsideInstallCheck
cd BroadsideInstallCheck
dotnet add package Broadside --version 1.0.0-rc.1
```

Replace `Program.cs` with:

```csharp
using Broadside;

using (PdfDocument created = PdfDocument.Create())
{
    created.Save("check.pdf");
}

using PdfDocument document = PdfDocument.Open("check.pdf");
Console.WriteLine($"{document.Pages.Count} page(s), {document.Diagnostics.Count} diagnostic(s)");
```

Then `dotnet run` must restore, build with no warnings, and print `1 page(s), 0 diagnostic(s)`. Record the result per operating system in the [gate checklist](v1.0.0-rc.1-gate.md).
