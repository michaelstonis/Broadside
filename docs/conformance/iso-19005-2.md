# ISO 19005-2:2011 PDF/A-2 (output)

ISO 19005-2 is not purchased (open decision 12): rows are keyed by the clause numbers of veraPDF's PDF/A-2B validation profile (veraPDF 1.28, `PDFA-2B.xml`), and the Notes cite its rule identifiers (clause and test number, e.g. 6.2.11.4.1-1). Titles paraphrase the profile's rule descriptions, not the standard's table of contents. Scope is conformant *output* (spec story 41): a save with `PdfSaveOptions.PdfAConformance` checks the document (`PdfAChecker`), refuses in strict mode or saves without claiming conformance in lenient mode (`PdfANonConformant`, `PdfANotIdentified`), and otherwise adds the output intent and identification. Input validation is out of scope. Every conformant file the tests write is validated by veraPDF in CI (job `verapdf`, story 42). Status: `not started` | `partial` | `done` | `n/a`.
