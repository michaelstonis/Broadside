# ICC.1:2022 Image technology colour management: architecture, profile format and data structure

Conformance map for the ICC profile format as Broadside reads it: the device-to-PCS direction of profiles embedded in ICCBased colour spaces (ISO 32000-2 §8.6.5.5), converted by the managed ICC engine, and the PCS-to-device lookup tables through `IccProfile.TryConvertFromConnectionSpace` in `Broadside.Rendering` (`IccColorManagement`). Broadside reads profiles; it does not write them. Clause titles are from `Specs/References/ICC.1-2022-05.pdf`.
