# The font resolver is one interface, asked in order, that also serves named font resources

ADR 0001 names the font resolver as an extension point and ADR 0007 says the Standard 14 glyphs ship in a separate package that the resolver falls back from; this records the contract both rely on. There is one interface, `IFontResolver`, with two members that each default to "not found": `ResolveFont` returns the bytes of a font program for a font that is not embedded (or whose embedded program cannot be read), with how it matches (exact name, Standard 14 stand-in, same family); `TryResolveResource` returns the bytes of a named CMap file, either a predefined CMap (Table 116) or a CID-to-Unicode table. An engine asks, in order, the resolvers registered with `PdfOptions.UseFontResolver`, then the operating system's (`SystemFontResolver`, a managed scan of the platform's font directories, replaceable or switched off with `UseSystemFontResolver`); the first answer wins. The policy around them stays in the core, so every resolver gets the same treatment: when none has the font itself, the core picks the most similar Standard 14 font from the descriptor's flags, metrics and name and asks again, never giving a symbolic font a text font; it records an information diagnostic for a substitution and for a font no resolver has, never throws for a machine's missing fonts in strict mode, keeps the PDF's widths for positioning, parses resolver bytes with the engine's font program parsers once per document, and parses resource bytes with its own CMap parser. Folding resources into the same interface means the predefined CMaps package (#54) plugs in without another extension point; returning bytes rather than parsed objects keeps resolvers simple and lets a replaced font program parser read substitutes too. Configured resolvers come before system fonts so output with the Standard 14 package is the same on every machine; a consumer who prefers a company font store registers it first. Resolvers are per engine (no static registry); only immutable bytes, and the default system font index, are shared by the process.
