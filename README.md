# Broadside

A fully managed .NET implementation of the PDF specification (ISO 32000-2 and its extensions): read, write, edit and render, with a cross-platform, cross-backend rendering layer and viewer controls to follow. MIT licensed. The goal is to be the only PDF dependency a .NET application needs.

**Status: planning complete, no code yet.** Start with [docs/plan/README.md](docs/plan/README.md).

## Specifications

`Specs/` is not committed. Place ISO 32000-2:2020 and the ISO/TS 32001 through 32005 documents there (free sponsored copies are available from the PDF Association), and download the free font, image and color references listed in [docs/specs-sources.md](docs/specs-sources.md) into `Specs/References/`.
