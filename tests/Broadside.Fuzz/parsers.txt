# Every parser and codec of the core (Broadside) and rendering (Broadside.Rendering) assemblies, with the fuzz targets that
# exercise it (issue #274). FuzzTargetMapTests (tests/Broadside.Rendering.Tests) fails when a parser or codec has no line here or
# a line names a target FuzzTargets.All does not register; the coverage report (docs/fuzz-coverage.md, coverage.sh) measures each
# target over the types mapped to it, the first target of a line being the one that owns the type.
#
# A parser or codec is a type behind the filter or font program parser extension point, a type whose name ends in Parser,
# Reader, Decoder, Tokenizer or Lexer, or one of the Phase 3 to 5 parsers named in the test.
#
# <full type name> <target> [<target>...]
