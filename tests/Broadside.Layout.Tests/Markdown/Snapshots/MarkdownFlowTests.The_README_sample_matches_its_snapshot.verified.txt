# Broadside

Broadside is a **fully managed** .NET PDF library: *read*, write, edit and render. See the guide or [https://github.com/michaelstonis/Broadside](https://github.com/michaelstonis/Broadside), and [www.example.com](http://www.example.com/).

## Getting started

Install the package:

dotnet add package Broadside

Then open a document:

using PdfDocument document = PdfDocument.Open("in.pdf"); string text = document.Pages\[0\].ExtractText().PlainText;

Every repair is recorded as a diagnostic. Strict mode throws instead.

## Features

1. Reading and repairing
2. Writing, with no native code
   - incremental updates
   - linearization
3. Rendering

- PDF/UA-2 output
- Footnotes
