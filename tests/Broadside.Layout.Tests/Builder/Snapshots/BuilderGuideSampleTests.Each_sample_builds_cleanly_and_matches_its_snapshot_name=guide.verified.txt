Installing
1. Add the Broadside package.
2. Add the optional packages you need:
– Broadside.Rendering, for PNG output
– Broadside.Fonts.Standard14, for non-embedded fonts
Reading files
Install the packages first (see Installing on page 2), or read the online guide.
Repairs and diagnostics
Reading is lenient: a damaged file is repaired, and every repair is recorded as a diagnostic on the
document.
Writing files
Save with Save or SaveAsync; a document built for a PDF/A or PDF/UA profile saves with it by
default.
