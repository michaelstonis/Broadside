Broadside is pre-alpha: the plan and the scaffolding exist, the library does not yet. These pages say what the project is building, how it is organized, and how to follow or join the work.

- [Getting started](getting-started.md): installation and first use, once there is a release.
- [Architecture](architecture.md): the terms used throughout the code and the architecture decision records.
- [Roadmap](roadmap.md): the phases, their tracks, and where progress is tracked.
- [Conformance](conformance.md): the per-clause record of what is implemented.
- [Contributing](contributing.md): the issue, branch and pull request flow.

The [API reference](../api/readme.md) is generated from the XML documentation in the source on every build of this site.
