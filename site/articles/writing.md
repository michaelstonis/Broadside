# Writing

This guide is being written for v1 ([#269](https://github.com/michaelstonis/Broadside/issues/269)). Like the [reading guide](reading.md), its code will come from compiled samples that CI runs.

It will show, with runnable samples: drawing on a page's canvas (paths, text, fonts and subsetting, images, transparency); flow layout with the `Broadside.Layout` package (paragraphs, lists, tables, headers and footers, right-to-left text); and the minimum PDF version of each feature.

Until then, [Getting started](getting-started.md#create-a-document) draws a first page, and [Building documents](building-documents.md) covers the document builder.
