# Editing

This guide is being written for v1 ([#269](https://github.com/michaelstonis/Broadside/issues/269)). Like the [reading guide](reading.md), its code will come from compiled samples that CI runs.

It will show, with runnable samples: incremental and full saves, and how an incremental save keeps an existing signature valid; page operations, merging and splitting; forms (filling, appearances, flattening); annotations; metadata; attachments; and encryption.

Until then, [Getting started](getting-started.md#change-it-and-save-it) changes and saves a file, and the [reading guide](reading.md#the-objects-under-the-model) shows the objects every edit works on.
